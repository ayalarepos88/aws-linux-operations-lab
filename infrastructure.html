Infrastructure Architecture

This environment is hosted on AWS EC2 and built around Red Hat Enterprise Linux 10. The platform combines web services, monitoring tools, containerized workloads, and source control management.

Current Architecture

Internet
    │
AWS EC2
    │
Red Hat Enterprise Linux 10
    │
Nginx Web Server
    │
├── Grafana
├── Prometheus
├── Node Exporter
└── Uptime Kuma

Components

AWS EC2

Virtual machine hosting the project environment.

Red Hat Enterprise Linux

Operating system used for administration, package management and services.

Nginx

Web server used to host portfolio content.

Podman

Container engine used to run monitoring services.

Grafana

Dashboard platform for infrastructure metrics.

Prometheus

Metrics collection and time-series database.
